| DPM-04 | Incorrect playability ratings | Console-exclusive titles not gated by ownership platform. **Patched**: `GET /:id/playable-games` gates owned games by the device's canonical platform family using EPIC-04 `AppOwnership.platformCanonical`; a PC-family device never renders console-exclusive titles.                                                                     | `src/routes/devices.ts`                          | Data/Backend | `FIXED-S3` |

| DPM-06 | Stale hardware specs          | No freshness timestamp on scanned rows. **Patched**: `lastScanAt` column on `Devices` (stamped on upsert/system scan), surfaced as `staleSpecs` in device + DPM responses and counted in the freshness baseline.                                                                                                                            | `src/routes/devices.ts`, `src/db.ts`             | Backend      | `FIXED-S3` |
| DPM-07 | Stale hardware specs          | `resolveFallbackDevice()` could mask missing-spec states. **Patched**: the playability API exposes `blockedSpecs`/`staleSpecs`/`usingFallback`; the UI renders a graceful "refresh device scan required" blocked state and never computes a matrix with missing RAM/VRAM.                                                                   | `public/app.js`                                  | UI (T1)      | `FIXED-S3` |
